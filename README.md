O código, os textos e o hardware evoluem juntos, mas têm estágios diferentes de validação. A [shield Juca/Pi R05](Hardware/Juca_PiZero2_Shield/R05/README.md) é a revisão em trabalho: Raspberry com componentes voltados para baixo, 13 jumpers PTH com capinhas e furos elétricos de 1 mm. R04 e R02 permanecem preservadas como histórico. Consulte o guia da R05 para o estado das verificações; montagem e integração UART com o carrinho permanecem pendentes de validação física.
